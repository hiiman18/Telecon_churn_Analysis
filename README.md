# Telecom Customer Churn Analysis Dashboard

## Project Overview
This project analyzes customer churn in the telecommunications industry using Power BI. The objective is to understand customer behavior, identify churn patterns, and provide insights that can help businesses improve customer retention.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Excel / CSV
- Data Analysis and Visualization

## Project Objectives
- Analyze total customers and churned customers.
- Calculate customer churn rate.
- Identify customer segments with higher churn.
- Analyze customer tenure and contract patterns.
- Understand customer retention and revenue-related trends.
- Create an interactive dashboard for business insights.

## Key KPIs
- Total Customers
- Churned Customers
- Churn Rate
- Customer Retention
- Customer Lifetime Value (CLTV), if included in the dashboard

## Dashboard Features
- Interactive charts and visualizations
- Customer segmentation
- Churn analysis
- KPI cards
- Filters and slicers

## Files Included
- Power BI dashboard (.pbix)
- Dashboard screenshot

## How to Use
1. Download the Power BI `.pbix` file.
2. Open it using Power BI Desktop.
3. Refresh the dataset if required.
4. Explore the dashboard using available filters and slicers.

## Project Outcome
This project demonstrates practical skills in data cleaning, data analysis, KPI development, and interactive dashboard creation using Power BI.
